# Zion 1.0.0 用户使用说明

> 给第一次接触 Zion 的朋友：照着这份说明，就能自己完成打开、使用、备份、配置微信读书。
> 不需要懂任何技术，跟着一步步做就行。

---

## 1. Zion 是什么

Zion 是一个**个人生活工作台**，用来帮你把"每天要做的事、读的书、花过的钱、身体状态、复盘思考"都放在一个地方，慢慢积累成自己的成长记录。

它更像一个**只属于你自己的小空间**，目前主要包含这些功能：

- **首页**：日期问候、人生倒计时、"今天最重要的事"、每日打卡
- **任务**：今日任务清单、长期计划、上一周复盘要点
- **复盘**：每日复盘、周复盘、月复盘、历史回顾
- **状态**：睡眠、步数、卡路里、活动、身体指标（BMI/体脂率）记录
- **账本**：记录每天的收入支出，查看每月概况
- **读书**：微信读书数据同步、书架进度、书评、金句收集
- **学习**：学习计划（求职/自媒体/英语/韩语等）里程碑管理
- **过去**：回顾已经过去的日子里你记录下的内容
- **Zion 栏（我）**：个人宣言、每日打卡情况、数据备份与恢复

Zion 不夸张地说"帮你改变人生"，它只是安静地帮你**记录和坚持**。

## 2. 如何打开 Zion

Zion 是一个网页应用，**不需要下载安装 App**，用 Chrome 浏览器打开网址即可。

**正式网址：**
```
https://xiaozetong407-hue.github.io/zion-workbench/
```

### 电脑上使用
1. 打开 Chrome 浏览器
2. 地址栏输入上面的网址，回车
3. 看到"Zion 工作台"页面就成功了

### 手机上使用
1. 手机 Chrome 浏览器打开上面的网址
2. 正常使用即可（建议开启"电脑版网站"？不需要——这就是为手机优化的页面）

### 推荐：安装到桌面/主屏（PWA）
用 Chrome 打开后，如果浏览器弹出"**安装**"提示，**建议选择安装**。

- 手机上：Chrome 右上角菜单 → **"添加到主屏幕"** 或 **"安装应用"**
- 电脑上：地址栏右侧的安装图标

**"安装"和"创建快捷方式"的区别：**
- **创建快捷方式**：只是桌面上多了一个图标，点开还是打开网页（还会显示浏览器地址栏）
- **安装**：像真正的 App 一样，有独立窗口、有自己的图标，打开更快，用起来更接近手机原生应用

安装后，你就可以像使用普通 App 一样使用 Zion 了。

## 3. 第一次使用（跟着做）

### 第 1 步：先认识页面
打开后你会看到**左侧一列小图标**（或底部一列图标），这是 Zion 的"导航栏"，代表各个栏目：

| 图标 | 栏目 | 作用 |
|---|---|---|
| zion | 我 | 个人宣言、打卡情况、数据备份 |
| 首页 | 首页 | 今天最重要的事、每日打卡 |
| 任务 | 任务 | 今日任务、长期计划 |
| 复盘 | 复盘 | 每日/每周复盘 |
| 状态 | 状态 | 睡眠、步数等身体记录 |
| 账本 | 账本 | 收入支出记账 |
| 读书 | 读书 | 微信读书同步、金句 |
| 学习 | 学习 | 学习计划管理 |
| 过去 | 过去 | 回顾历史记录 |

### 第 2 步：先做一件小事——去"首页"打个卡
1. 点左侧"**首页**"
2. 在"**每日打卡**"里，点一下今天做到的项（比如"早睡""运动"）
3. 点"**保存打卡**"——完成！这就是你的第一条记录

### 第 3 步：记一个任务
1. 点"**任务**"
2. 在"今日任务"输入框写下今天要做的事（比如"写周报"）
3. 回车或点添加，完成后再点一下任务前的圆圈，就标记完成了

### 第 4 步：认识你的"我"（Zion 栏）
点左侧第一个"**zion**"，这里有你的一段**个人宣言**，下面是**数据备份**区——先不用动它，但要记住它在哪（后面第 6 节会用到）。

到这里，你就已经会使用 Zion 的核心操作了。剩下的功能都是类似的方式：**点开栏目 → 填写 → 保存**。

## 4. 各栏目简单介绍

- **首页**：每天打开的第一个页面。"今天最重要的事"会显示你在前一天复盘里写下的明日重点；"每日打卡"是简单的坚持记录（外语学习/运动/阅读/早睡/低碳饮食/记账）。
- **任务**：管理今天要做的事，以及长期计划（把大目标拆成小步骤）。右上角或底部可以查看历史任务。
- **复盘**：每天睡前花两分钟写"今日总结、明日计划"；每周日做一次"周复盘"；还有月复盘、年复盘和完整的历史回顾。
- **状态**：记录每天的睡眠小时、步数、卡路里、活动时间，以及身高体重（身高体重填好后会自动计算 BMI 和体脂率）。
- **账本**：记每一笔收入或支出，月底看"本月花了多少、赚了多少"。
- **读书**：同步你的微信读书数据（见第 7 节），也可以手动收藏喜欢的句子（金句）。
- **学习**：为不同的学习目标（比如求职、英语、韩语）建立计划，一步步打勾完成。
- **过去**：回看过去每天记录下的内容，见证自己的积累。

## 5. 最重要的一个概念：数据保存在哪里

**Zion 默认把你的个人数据保存在"当前这台设备的浏览器"里。**

也就是说：

- 手机上的 Zion 数据，**只存在手机里**
- 电脑上的 Zion 数据，**只存在电脑里**
- 它们默认**不会自动互相同步**

如果你换了手机、换了电脑、或者清了浏览器数据，之前的内容**不会自动跟着你走**。

那怎么办？——用第 6 节的"**导出备份 + 导入**"来迁移，很简单。

## 6. 数据备份与恢复（强烈建议养成习惯）

**进入方式**：点左侧"**zion**"（我）→ 找到"**数据备份**"。

这里有三个按钮：

- **导出备份**：把当前所有数据保存成一个文件（JSON 格式），下载到你的设备
- **恢复备份**：把之前导出的备份文件导入回来（换设备时用这个）
- **恢复上一次备份**：如果刚才导入出了问题，可以用这个回到上一次的备份状态

### 什么时候该备份？
建议在以下情况**先备份**：

- 准备更换手机 / 电脑
- 更换浏览器
- 升级重要版本之后
- 准备大规模修改数据之前
- **每周做一次例行备份**更稳妥

### 备份文件放哪？
导出的文件是普通文件，可以保存在：

- OneDrive / iCloud / Google Drive 等网盘
- U 盘
- 电脑本地文件夹

**不要**把备份文件上传到 GitHub、发到群里或公开网络——里面包含你的个人数据。

## 7. 微信读书同步

Zion 可以同步你在微信读书里的书架、阅读时长、书评和划线金句。

### 第一次使用
1. 点左侧"**读书**"
2. 在"微信读书"区域，粘贴你的 **WRK-Key**（以 `wrk-` 开头的一串字符，在微信读书 App 的官方 Skill 设置中可以获取）
3. 输入后会自动开始连接和同步，稍等片刻即可看到书架和阅读数据

### 之后的使用
只要你的浏览器还保存着设置，**以后打开"读书"会自动读取 Key 并同步，不需要每次重新输入**。也可以随时点"重新同步"更新数据。

### ⚠️ 关于 WRK-Key 的安全（非常重要）
WRK-Key 相当于你微信读书账号的"钥匙"，**属于个人凭证**：

- **不要发给别人**、不要发到群里
- **不要写进公开文档、截图、代码**
- **不要上传到 GitHub 或任何公开网站**

**如果你想把自己的微信读书同步给朋友用，必须让朋友使用他自己的 WRK-Key**，不要共用你的 Key。

## 8. 微信读书代理说明（了解即可，一般不用动）

微信读书的数据需要通过一个"中转"才能同步进来。对普通用户来说：

- **默认情况下，直接打开"读书"粘贴 Key 就能尝试同步**，不需要做任何设置
- 如果同步时出现"代理不可达 / 网络层失败"之类的提示，可以进入"**我 → 微信读书代理（高级）**"查看，但**不建议普通用户手动修改代理地址**
- 如果未来代理地址发生变化（服务调整等原因），届时按最新说明重新配置即可

**本文档不会、也不应该出现任何密钥或敏感地址细节**——你只需要知道有这回事就够了。

## 9. 隐私与安全

用普通人能听懂的话说清楚：

- **"把 Zion 发布到 GitHub" ≠ "把你的个人数据发布到 GitHub"**
- GitHub 上存放的是 Zion 的**程序代码**，用来让所有人打开这个网页
- **你的任务、账本、复盘、状态、阅读数据，默认只保存在你自己的浏览器里**，Zion 不会把它们上传到 GitHub 或任何服务器
- 你的 **JSON 备份文件由你自己保管**，放在安全的地方
- 你的 **微信读书 Key 不应该公开**，任何人都不该在公开场合看到它

一句话：**程序是公开的，你的数据是你自己的。**

## 10. 常见问题

**Q1：换手机后，数据没了怎么办？**
A：在旧手机 Zion 里"我 → 数据备份 → 导出备份"，得到备份文件；再把文件发到新手机（微信文件传输助手、网盘都行），在新手机打开 Zion → "恢复备份" → 选择这个文件，数据就回来了。

**Q2：为什么电脑和手机上的数据不一样？**
A：Zion 的数据默认存在"各自的浏览器"里。电脑的数据在电脑、手机的数据在手机，互不干扰。想让两边一样，就用"导出 + 导入"。

**Q3：为什么打开网站时浏览器提示可以"安装"？**
A：因为 Zion 是 PWA（渐进式网页应用），它允许浏览器把它"安装"成独立应用。这是正常功能，放心安装。

**Q4：安装和创建快捷方式有什么区别？**
A：安装后像真正的 App，有独立窗口、自己的图标、打开更快；快捷方式只是桌面上一个"打开网页"的入口，点开还是浏览器里的网页。

**Q5：微信读书为什么同步失败？**
A：按顺序检查：
1. 确认 Key 是否复制完整（以 `wrk-` 开头，没有多余空格）
2. 确认手机/电脑能正常上网
3. 关闭页面重新打开（有时是网络临时波动）
4. 看页面上的错误提示文字，按提示处理（比如"Key 无效"就去微信读书重新获取）
普通用户**不需要也不建议修改任何代码**。

**Q6：误删了数据怎么办？**
A：如果你之前导出过备份文件，用"恢复备份"导回来即可。如果只是最近一次导入操作出问题，可以试"恢复上一次备份"。

## 12. 推荐使用习惯（实用版）

**每天（1–2 分钟）**
- 打开首页 → 看一眼"今天最重要的事" → 打卡
- 到"任务"里，把今天要做的事标记完成

- 到"我 → 数据备份"做一次导出备份

保持这个节奏，Zion 会慢慢积累成你真实的成长记录。坚持的价值，时间会给你答案。
