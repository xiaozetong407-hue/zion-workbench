# 源码与配置说明（开发细节）

本目录是 **zion-workbench** 的开发细节，**不是给最终使用者看的成品**。

包含内容：
- `src/` —— 全部源码（React 组件、样式、本地存储/同步逻辑）
  - `src/App.jsx` —— 应用入口、侧栏导航、二级页返回逻辑、tab 持久化
  - `src/components/` —— 各模块组件：Home / Review / Ledger / LedgerHistory / Reading / Past / Study / Status / Me / zion 等
  - `src/store/` —— 数据层：`db.js`（业务读写，localStorage 主键）、`sync.js` + `onedrive.js`（可选 OneDrive 同步）、`todo.js`（To Do 集成，按约定未启用）
  - `src/utils/date.js` —— 日期/周期辅助函数
  - `src/styles.css` —— 集中样式（CSS 变量 Token：`--ink` / `--life-red` / `--life-orange` 等）
- `index.html` / `public/` —— 应用入口与静态资源（icon.svg / manifest.webmanifest）
- `vite.config.js` / `package.json` / `package-lock.json` —— 构建与依赖配置
- `node_modules/` —— 依赖包（由 `npm install` 生成）

后端/代理（按需启用）：
- `server.js` —— 本地 Node 服务：托管 `成品与文档/dist` + 转发微信读书/华为代理
- `huawei.mjs` —— 华为授权/拉取共享模块
- `scripts/huawei-auth.mjs` —— 华为一次性授权脚本（`npm run huawei:auth`）
- `weread-proxy-worker.js` —— Cloudflare Worker（纯静态微信读书代理）

资源：
- `app-icon/` —— 各尺寸应用图标 + `gen_icon.py`
- `huawei-form/` —— 华为 HealthKit 申请资料（Excel / 隐私政策 / 用户协议 HTML）

如何运行：
```bash
npm install      # 首次或依赖变更后
npm run dev      # 本地开发，浏览器打开终端输出的地址（默认 http://localhost:5173）
npm run build    # 构建成品，自动输出到 成品与文档/dist
```

成品与文档请见同级目录 **`成品与文档/`**（工作简报、开发文档、源码说明、构建后的网页）。
