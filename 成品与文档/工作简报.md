## 一、项目背景与定位

Zion 工作台是一个**个人一体化成长/生活管理台**（移动端 PWA，可"添加到主屏幕"当 App 用）。首页是"今天的主控台"，把时间、任务、习惯打卡、健康、账本、阅读、学习、复盘聚合到一起；所有模块的每日数据在周报/月报（过去页）中自动沉淀。

设计基调：
- **首页即主控台**：时间日期 + 最重要的事 + 打卡入口，一眼看到今天该做什么。
- **每日数据 → 周报/月报自动汇总**（过去页可视化）。
- **长周期计划（月/年/5 年）只备忘、不计完成**。
- 复用已有数据：华为运动健康（一次性授权拉取）、微信读书（API Key + 代理）；**Microsoft To Do 不接入**（个人自用优先本地，按约定不接 To Do）。

## 二、当前核心范式：手动「记录日」（重要）

> 2026-07-30 起，用户明确取消"凌晨 6 点自动清空/滚动"逻辑，改为**手动驱动**。

| 面板 | 当日主键 | 推进方式 |
|------|----------|----------|
| 首页打卡 | 记录日(checkInDay) | 点「保存打卡」→ +1 下一天；单项打卡先存**本地草稿**(localStorage `zion-checkin-draft`)，只有点保存才入库，切界面/刷新不丢 |
| 复盘 | 记录日(reviewDay) | 点「保存」→ +1 下一天，并清空输入框 |
| 状态 | 记录日(statusDay) | 点「保存状态」→ +1 下一天，并清空输入框 |
| 任务 | 记录日(taskDay) | 点「下一天 →」→ +1；每次勾选/增删即按日期存档前一天 |
| 账本 | 真实时间 | 每分钟校准，跨零点自动跳到新的一天（不跟记录日） |

- 四个记录日各自独立计数，互不串台。
- 刷新停留原页面（localStorage `zion-tab` 持久化当前 tab）。
- 首页打卡带日期选择器，可补录任意一天（如误删某日打卡可重选日期重建）。

## 五、部署与运行

- **公网部署**：CloudStudio 静态托管（沙箱复用，地址稳定）。
- **本地开发**：
  ```bash
  npm install          # 首次或依赖变更后
  npm run dev          # 本地开发，默认 http://localhost:5173
  npm run build        # 构建到 成品与文档/dist（先 rm -rf 旧 dist 再 build，规避 OneDrive shim）
  npm run serve        # 起 Node 服务(默认4173)，含微信读书/华为代理
  ```
- **微信读书纯静态连接**：需配套代理（Cloudflare Worker `weread-proxy-worker.js` 或 `npm run serve` 同 WiFi）；不填代理 = 无法连 weread（架构限制，非 App bug）。
- **P0 视觉规则**：全 SVG 描边图标，禁止 emoji 图标；禁止紫→粉渐变；禁止 AI 模板味 placeholder 灰字。
